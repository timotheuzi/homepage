**Important Note on Data Storage:** All data collected, processed, and stored by Dark Work Labs remains exclusively on your device. ## 2. Information We Collect

Since all data remains on your device, we do not collect any personal information from you. The application processes the following types of data locally:

### Device Information
- Device model and manufacturer
- Android version and build number
- Device identifiers (IMEI, serial number) - used only for device identification
- Hardware specifications

### Network Information
- WiFi network names (SSIDs)
- Network interface information
- IP addresses of devices on your network
- MAC addresses of detected devices
- Open ports and services on network devices

### Bluetooth Information
- Bluetooth device names and addresses
- Signal strength measurements
- Device types and capabilities
- Proximity information

### Sensor Data
- Accelerometer readings
- Gyroscope measurements
- Magnetometer data
- GPS/location coordinates (when permitted)
- Proximity sensor states
- Light sensor readings

### System Information
- CPU usage statistics
- Memory usage data
- Disk usage information
- Running processes and applications
- System logs and events
- Battery status

### File System Information
- File names and paths (for scanning purposes)
- File metadata (size, type, creation date)
- File content signatures (for malware detection)
- No file contents are stored or transmitted

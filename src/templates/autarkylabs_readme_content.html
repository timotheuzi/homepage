Autarky Labs: The Great Defender 🛡️

Package Name: com.autarky.labs
Version: 1.0.0+1
Platform: Android & Linux

A comprehensive, intelligent security monitoring application built with Flutter, designed for Android and Linux. AutarkyLab acts as a digital sentinel, merging advanced reconnaissance tools with AI-driven anomaly detection into a modern, beautiful interface.

🚀 Overview

Autarky Labs provides real-time oversight of your digital and physical environment. Under the watchful eye of the Great Defender, it uses machine learning patterns to detect anomalies in network traffic, Bluetooth signals, and hardware sensor data.

All data processing and storage occurs exclusively on your device; no data is ever transmitted or saved outside of your phone.

✨ Features

🔍 Network & WiFi Sentinel

  • Automated Reconnaissance: Scans local networks for nodes, open ports, and disappearing devices.
  • Vulnerability Auditing: identifies suspicious services (RDP, Telnet, FTP, SMB) and performs web security tests (XSS, SQLi).
  • WiFi Security: Detects Rogue Access Points, Evil Twin attacks, and unencrypted networks.

📡 Bluetooth & RF Surveillance

  • Sentinel Eye Detection: Monitors for KNOB, BIAS, and BlueBorne vulnerabilities in nearby Bluetooth nodes.
  • AirTag Identification: Monitors BLE for Apple AirTags and Find My network-enabled trackers.
  • RF Spectrum Monitor: Integration with external SDR hardware (RTL-SDR) to detect Sub-GHz surveillance signals.

🤖 AI Neural Core

  • Pattern Learning: The Neural Core learns environmental threat patterns over time to improve detection accuracy.
  • Signal Anomaly Detection: Uses standard deviation analysis to flag sudden, suspicious signal strength changes.

📊 Hardware Telemetry

  • Real-time Streams: Live monitoring of Accelerometer, Gyroscope, Magnetometer, and Ambient Light.
  • System Vitals: Detailed tracking of CPU, memory, battery health, and active network sockets.

📁 File Integrity Scanner

  • Deep Analysis: Scans local file systems for suspicious patterns, dangerous extensions, and risk indicators.

🎨 The Great Defender UI

  • Unified Dashboard: Real-time security status provided by the Sentinel Shield.
  • Normalized Experience: Consistent, premium design language across all security modules.
  • Detailed Intelligence: Categorized threat logs with incident analysis and mitigation suggestions.

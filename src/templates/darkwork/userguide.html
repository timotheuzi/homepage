Welcome to the Dark Work Factory Labs user guide. This document provides a comprehensive overview of the application's features, how to interpret the data, and how to maximise your security posture using our tools.

1. Introduction

Dark Work Factory Labs is a multi-platform security suite providing real-time monitoring of your network, Bluetooth environment, physical hardware sensors, file system, system resources, and radio frequencies to protect you from digital and physical intrusions.

2. Key Features

  • Network Security Scanner
  • Bluetooth Monitor
  • Sensor Analysis
  • File System Scanner
  • System Monitor
  • Radio Frequency Monitor
  • AI Neural Core
  • Intelligence Dashboard

3. Getting Started

Required Permissions

  • Location - For network discovery and Bluetooth scanning
  • Storage - For file system scanning
  • Bluetooth - For Bluetooth device monitoring
  • WiFi - For network security analysis
  • Notifications - For security alerts
  • Phone - For device identification

4. Using the Application

The app uses a bottom navigation bar with five main sections: STATUS, SENSORS, SECURITY, SYSTEM, and MORE.

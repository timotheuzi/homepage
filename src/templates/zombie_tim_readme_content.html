🧟 Zombie Tim 🧟

Zombie Tim is a cross-platform, AI-powered personal assistant with a twist—he's undead! Tim lives in your device and helps you manage your life while satisfying his hunger for knowledge (and brains).

Built with Flutter, Zombie Tim runs seamlessly on Android, iOS, Web, Linux, macOS, and Windows.

✨ Features

  • 🧠 Interactive Chat: Talk to Tim via a blood-splattered, animated interface. He responds with a unique zombie personality.
  • 📅 Proactive Assistant: Tim can now manage your schedule:
    • Reminders: Set time-based alerts so you never forget a thing.
    • Task Management: Keep a "to-do" list with due dates and priorities.
    • Notes: Capture quick thoughts or detailed logs in Tim's digital brain.
  • 📚 Dynamic Vocabulary: Tim learns as you go. Use eat word to expand his knowledge base.
  • 🔍 Brain Scanning: Tim can forage through your device storage to find information or "sniff out" new words from the web.
  • 💻 Developer Tools: Tim is a tech-savvy zombie. He can generate code snippets in various languages and explain complex technical concepts.
  • 🎱 Magic 8-Ball: Get undead predictions for your most pressing questions.
  • 🔒 Security Monitoring: Tim can perform comprehensive security audits:
    • Full Security Scan: Complete network and Bluetooth security analysis
    • Network Monitoring: Check active connections and detect suspicious activity
    • Bluetooth Surveillance: Monitor paired and nearby Bluetooth devices
    • Cross-Platform Support: Works on Linux, Windows, and macOS

🚀 Getting Started

  1. Installation: Download the latest release for your platform or build from source.
  2. First Run: Tim will initialize his SQLite "Brain Database" on your device.
  3. Usage: Jump into the Chat screen and start by saying "Hello" or use one of the special commands.

Refer to the USER_GUIDE.md for a full list of commands and interaction tips.

🔒 Security Features

Zombie Tim has been upgraded with comprehensive security monitoring capabilities. The zombie assistant can now check your network, scan for suspicious connections, monitor Bluetooth devices, and provide detailed security reports.

Security Commands

1. Full Security Scan

Command: security scan or check security or security check

Performs a complete security audit including:

  • Network connectivity status
  • All active network connections
  • Suspicious connection detection
  • Bluetooth status and paired devices
  • Nearby Bluetooth devices
  • Comprehensive security report

2. Network Check

Command: check network or network status or check connections

Provides a quick network overview:

  • Connection status
  • Number of active connections
  • First 5 connections displayed
  • Warnings if suspicious activity detected

3. Bluetooth Check

Command: check bluetooth or bluetooth status

Monitors Bluetooth devices:

  • Bluetooth availability and status
  • Paired devices list
  • Nearby detected devices

Security Monitoring Capabilities

Network Monitoring:

  • Connectivity Check: Tests internet connectivity via ping
  • Connection Scanning: Lists all active network connections
  • Port Analysis: Identifies services running on suspicious ports
  • Process Detection: Shows which processes own connections

Suspicious Activity Detection:

The system monitors for:

  • Known suspicious ports (4444, 5555, 6667, 1234, 31337, 12345)
  • Suspicious process names (netcat, reverse shell, backdoor, miners)
  • Unusual connection patterns

Bluetooth Monitoring:

  • Status Detection: Checks if Bluetooth is available and enabled
  • Paired Devices: Lists all trusted paired devices
  • Nearby Devices: Detects unknown devices in range
  • Cross-Platform: Works on Linux, Windows, and macOS

Platform Support

Linux:

  • Uses ss command for connection scanning
  • Uses bluetoothctl for Bluetooth monitoring
  • Uses ping for connectivity checks

Windows:

  • Uses netstat -ano for connection scanning
  • Uses PowerShell for Bluetooth status
  • Uses ping for connectivity checks

macOS:

  • Uses ss command for connection scanning
  • Uses system_profiler for Bluetooth info
  • Uses ping for connectivity checks

Privacy & Security

What Gets Scanned:

  • Active network connections (local addresses and ports)
  • Bluetooth device names and addresses
  • Process names associated with connections
  • Network connectivity status

What Doesn't Get Scanned:

  • No packet inspection
  • No content monitoring
  • No data collection or transmission
  • All processing happens locally on your device

Integration with Chat

The security features are fully integrated into ZombieTim's chat system. Simply type any of the security commands in the chat interface, and Zombie Tim will:

  1. Perform the requested scan
  2. Format the results in a zombie-themed report
  3. Add personality and humor to the findings
  4. Provide actionable warnings if issues are detected

Technical Details

SecurityService Class:

  • Singleton pattern for efficient resource usage
  • Platform detection for cross-platform support
  • Timeout protection for all system commands
  • Error handling with zombie-themed error messages

Report Structure:

class SecurityReport {
  String networkStatus;
  List activeConnections;
  List suspiciousConnections;
  BluetoothStatus bluetoothStatus;
  List warnings;
  DateTime timestamp;
}

Command Execution:

All system commands are executed with:

  • 5-second timeout protection
  • Error catching and logging
  • Platform-specific command selection
  • Safe output parsing

Future Enhancements

Potential additions:

  • WiFi network scanning
  • Port vulnerability checking
  • Historical security tracking
  • Automated security alerts
  • Integration with system notifications
  • Export security reports to file

Notes

  • Security scans require appropriate system permissions
  • Some features may be limited on mobile platforms
  • Bluetooth scanning works best on desktop platforms
  • All scans are read-only and don't modify system state

🛠 Building from Source

Zombie Tim uses a Makefile for streamlined builds:

# Build for Android
make android

# Build for Linux
make linux

# Run tests
make test

Note: For macOS and iOS builds on Linux hosts, we provide Podman/Ansible automation (see Makefile).

🔒 Privacy

Your data stays in your grave. All interactions, reminders, tasks, and notes are stored locally on your device using an encrypted-ready SQLite database. No personal data is sent to our servers. See PRIVACY_POLICY.md for details.
